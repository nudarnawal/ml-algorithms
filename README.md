# ML Projects
1. Linear Regression — Student Performance Prediction

A machine learning project using multiple linear regression to predict students' Performance Index based on five features:

Hours Studied
Previous Scores
Extracurricular Activities
Sleep Hours
Sample Question Papers Practiced

The project includes:

Data loading and preprocessing

Categorical data encoding

Train-test splitting

Linear regression model training

Performance Index prediction

Actual vs. predicted value comparison

Model evaluation using Mean Absolute Error (MAE) and R² Score

Dataset: Student Performance

Model: Multiple Linear Regression

Results:

Mean Absolute Error: 1.61

R² Score: 0.989
